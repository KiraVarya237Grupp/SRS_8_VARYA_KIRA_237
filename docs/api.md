# Спецификация REST API

Все изменяющие запросы (`POST`, `PATCH`) требуют передачи заголовка `X-CSRFToken` и выполняются в рамках атомарной транзакции `transaction.atomic()`.

---

## 1. Получение списка записей каталога с фильтрацией

| Параметр | Описание |
| :--- | :--- |
| **Метод и адрес** | `GET /api/entries/` *(или `/catalog/api/entries/?status=in_progress&genre=1&q=Гарри`)* |
| **Назначение** | Получение списка карточек медиатрекера текущего пользователя с фильтрацией по жанру, статусу и поисковой строке |
| **Аутентификация** | Сессия пользователя (или параметр выбранного контура владельца `owner`) |
| **Тело запроса** | Не требуется (параметры передаются в Query String: `status`, `genre`, `q`) |
| **Успех** | `HTTP 200 OK`, JSON-массив объектов `WatchEntry` со связанными данными `Title`, `FormatInstance` и допустимыми переходами |
| **Ошибки** | `400 Bad Request` — переданы некорректные параметры фильтрации |
| **Проверка** | Вкладка Network (`Fetch/XHR`) при переключении кнопок «Фильтр 1 (Жанр)», «Фильтр 2 (Статус)» или вводе текста в поиск |

**Пример успешного ответа (`200 OK`):**
```json
[
  {
    "id": 3,
    "title": "Гарри Поттер и философский камень",
    "kind": "Книга",
    "status": "planned",
    "status_display": "В планах (Отложено)",
    "format_used": "Бумажная",
    "rating": 3,
    "notes": "",
    "allowed_transitions": ["in_progress"]
  }
]
```

## 2. Создание новой записи в библиотеке

| Параметр | Описание |
| :--- | :--- |
| **Метод и адрес** | `POST /api/entries/create/` |
| **Назначение** | Добавление нового произведения в личную библиотеку со статусом `planned` и записью события `created` в `EntryEvent` |
| **Аутентификация** | Требуется сессия пользователя и заголовок `X-CSRFToken` |
| **Тело запроса** | `{"title_id": 5, "format_id": 2, "rating": 9, "notes": "Посмотреть на выходных"}` |
| **Успех** | `HTTP 201 Created` (или `200 OK`), JSON созданной карточки |
| **Ошибки** | `400 Bad Request` — не указано произведение или оценка вне диапазона 1–10; `403 Forbidden` — отсутствует CSRF-токен |
| **Проверка** | Отправка формы «+ Добавить запись» в интерфейсе, появление карточки и лога в `/admin/catalog/entryevent/` |

## 3. Транзакционная смена статуса записи (Экспресс-кнопки и тест отката)

| Параметр | Описание |
| :--- | :--- |
| **Метод и адрес** | `PATCH /api/entries/<id>/transition/` *(или `POST /api/entries/<id>/status/`)* |
| **Назначение** | Перевод записи личной библиотеки по жизненному циклу (`planned` -> `in_progress` -> `completed`) и автоматическая запись события в историю `EntryEvent` |
| **Аутентификация** | Требуется сессия владельца записи (`owner`) и заголовок `X-CSRFToken` |
| **Тело запроса** | `{"status": "in_progress"}` *(или `{"status": "in_progress", "simulate_error": true}` при нажатии кнопки «Сбой»)* |
| **Успех** | `HTTP 200 OK`, JSON обновлённой карточки с новым статусом |
| **Ошибки** | `400 Bad Request` — нарушение правил `ALLOWED_TRANSITIONS` или искусственный сбой транзакции (выполнен откат); `403 Forbidden` — попытка изменить запись другого профиля; `404 Not Found` — запись не найдена |
| **Проверка** | В Network виден запрос при клике на кнопку «Начать» / «Сразу готов» / «Сбой», изменение подтверждено в БД и журнале `EntryEvent` |

**Пример ответа при успешном переходе (`200 OK`):**
```json
{
  "id": 3,
  "status": "in_progress",
  "status_display": "Читаю / Смотрю сейчас",
  "message": "Статус произведения успешно обновлён"
}
```
**Пример ответа при успешном переходе (`200 OK`):**
```json
{
  "id": 3,
  "status": "in_progress",
  "status_display": "Читаю / Смотрю сейчас",
  "format_available": false,
  "message": "Статус успешно обновлён, носитель зарезервирован"
}
```

**Пример ответа при нажатии кнопки «Сбой» (`400 Bad Request`):**
```json
{
  "error": "Сбой транзакции (откат выполнен): Искусственный сбой транзакции для проверки отката!"
}
```

## 4. Получение истории событий (Аудит записи)

| Параметр | Описание |
| :--- | :--- |
| **Метод и адрес** | `GET /api/entries/<id>/events/` |
| **Назначение** | Чтение хронологического журнала операций (`EntryEvent`) по конкретной записи библиотеки |
| **Аутентификация** | Сессия пользователя |
| **Тело запроса** | Не требуется |
| **Успех** | `HTTP 200 OK`, JSON-массив событий с полями `event_type`, `description`, `initiator`, `timestamp` |
| **Ошибки** | `404 Not Found` — запись не существует |
| **Проверка** | Просмотр истории изменений карточки в UI и сверка с таблицей `История библиотеки` в админ-панели |
